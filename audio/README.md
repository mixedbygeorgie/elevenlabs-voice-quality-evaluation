# Audio File Manifest

This folder contains the six generated outputs evaluated in this listening test.

## Generated outputs

* `en_clean.mp3`
* `en_challenged.mp3`
* `no_clean.mp3`
* `no_challenged.mp3`
* `es_clean.mp3`
* `es_challenged.mp3`

## Generation setup

* Product: ElevenLabs Instant Voice Cloning
* Model: Eleven Flash v2.5
* Voice settings: Stability 50, Similarity 75, Style 0
* Clean source profile: iPhone 15 Pro
* Challenged source profile: MacBook Air 13-inch, M3
* Speaker and consent: the evaluator’s own voice

The labels `clean` and `challenged` identify two practical source-capture profiles. Because different recording devices were used, the comparison should not be interpreted as a strict single-variable experiment.

## Reference limitation

The original source recordings are not currently included in this repository. The identity scores therefore document the evaluator’s expert comparison against his own voice, but external listeners cannot independently verify identity fidelity from the generated outputs alone.
