# Submission Checklist

## Before testing

- [ ] Use only your own voice or obtain explicit consent.
- [ ] Remove client, confidential and copyrighted material.
- [ ] Record exact product/model, settings and date.
- [ ] Decide one controlled comparison.
- [ ] Keep source scripts short and redistributable.

## Before publishing

- [ ] Replace every bracketed placeholder.
- [ ] Complete at least six scored output rows.
- [ ] Add timestamped evidence for artifacts or pronunciation issues.
- [ ] State limitations and avoid universal claims.
- [ ] Label generated audio clearly.
- [ ] Confirm audio files contain no personal metadata.
- [ ] Verify repository links and file names.
- [ ] Update README status from planned to completed.

## Before submitting the application

- [ ] Insert the live repository URL into the application answer.
- [ ] Name the actual ElevenLabs product/model used.
- [ ] Include one honest, specific finding.
- [ ] Confirm the answer does not claim customer or commercial impact.
- [ ] Make the GitHub repository public.
- [ ] Preview the resume and application form one final time.
